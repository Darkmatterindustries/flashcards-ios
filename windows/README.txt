Flashcards 3.0 for Windows x64

Extract the entire ZIP into a folder, then open Flashcards.exe.
Keep the www folder and DLL files beside the executable.
Requires Windows 10/11, .NET Framework 4.7.2 or newer and Microsoft Edge WebView2 Runtime.
WebView2 download: https://developer.microsoft.com/microsoft-edge/webview2/

Decks and settings are saved in your Windows user profile, independently of the app folder.
Moving the extracted app folder preserves your data. Cloud backup/restore transfers supported data between platforms; it is not automatic live merging.
Bundled pronunciation audio works offline. Newly imported words outside the audio catalog use available device speech.

Study shortcuts: Enter/Space flip, Left repeat, Right memorize, Down/Escape return.
This is an unsigned preview build, not a Microsoft Store release.
